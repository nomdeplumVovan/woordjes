# Исходники словников

Сюда кладём выгрузку `Woordenlijsten Thema 1-8` из личного кабинета
leren.kleurrijker.nl (TaalCompleet A2 → EXTRA).

Файл — личная лицензионная копия, в репозиторий не коммитится (см. .gitignore).
Конвертер `tools/import-woordenlijst.mjs` разбирает его в `public/data/*.json`.
