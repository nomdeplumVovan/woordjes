# Woordjes

Тренажёр нидерландских слов по учебнику **TaalCompleet A2** (KleurRijker, 11e druk 2025).
Ionic + Angular, работает офлайн, без бэкенда: всё хранится в IndexedDB браузера.

Режимы тренировки:

- **перевод** в обе стороны — `nl-ru` (узнать) и `ru-nl` (вспомнить);
- **артикль** `de`/`het` — отдельный навык со своим прогрессом;
- **формы неправильных глаголов** — прошедшее время и перфект целиком, вместе с `hebben`/`zijn`.

В разборе ответа слово можно прослушать — системным синтезатором, офлайн. Если нидерландского
голоса в системе нет, озвучка выключается: прочитать `huis` английским голосом хуже, чем
промолчать. Как поставить голос, написано на экране импорта.

Повторение интервальное, по коробкам Лейтнера: 1, 2, 4, 8, 16 дней.

Прогресс можно выгрузить в файл и восстановить на другом устройстве — экран **Back-up**.
Слова в копию не попадают, только коробки: словарь возвращается импортом PDF. Это не
излишество, а необходимость: на iOS у вкладки Safari и у приложения с домашнего экрана
разные хранилища, и удаление иконки стирает занятия безвозвратно.

## Словарь приносит пользователь

Приложение поставляется **без лексики**. При первом запуске оно ведёт на экран импорта,
куда нужно загрузить свои PDF из личного кабинета leren.kleurrijker.nl (TaalCompleet A2 → EXTRA):

| файл | что даёт |
|---|---|
| `Woordenlijst Russisch` | параграфы и слова с переводами |
| `Onregelmatige werkwoorden` | формы неправильных глаголов, отделяемые приставки |

Порядок значения не имеет: если справочник глаголов приходит вторым, уже сохранённые слова
дополняются приставками и тегом `onregelmatig`. Тип файла определяется по содержимому, а не
по имени. Разбор идёт целиком в браузере — файл никуда не отправляется.

Так решается вопрос авторских прав: лицензия издателя выдаётся на одного человека, поэтому
раздавать копию словника нельзя даже тем, у кого лицензия есть. Каждый использует свою.

## Разработка

```bash
npm install
npm start -- --port 4300     # 4200 занят другим проектом
```

Тесты — Vitest, IndexedDB подменяется через `fake-indexeddb`:

```bash
npm test
```

Парсеры проверяются на настоящих PDF издателя (`core/import/woordenlijst.spec.ts` — и словник,
и справочник глаголов). Файлы лицензионные и в репозитории не лежат, поэтому без них эти тесты
пропускаются, а остальные идут как обычно.

## Сборка

```bash
npm run build                # dist/woordjes
npm run pwa:serve            # сборка + раздача на :4400, чтобы проверить service worker
npm run pwa:tunnel           # тот же :4400 наружу через cloudflared — для проверки на телефоне
npm run icons                # перерисовать public/icons/ — и растр, и сам source.svg
```

`pdfjs` уезжает в ленивый чанк: он весит больше самого приложения, а нужен только на импорте.

## Лицензия

Код — личный проект. Лексика учебника защищена авторским правом издателя, в репозитории её нет
и быть не должно: `public/data/` и `tools/source/` закрыты в `.gitignore`.
